# lab4.1-variables-and-functions

Reflection 

My approach to this task was to break down each task bit by bit to understand what was being asked and assigning the appropriate parameters. I took the tasks step by step and was able to make changes based on classroom assignments. I learned that parameters make functions reusable and the values were the parts being changed. I also started using default parameters when an input, such as the discount, was not required during the calculation.


One challenge I had was in organizing the functions to get them working well enough to submit. I had to reorganize the codes many times. Class time made it helpful in understanding how to use if statements and logical operators to check multiple conditions. I also had to remember to use return instead of console.log() when the instructions asked the function to return a result. At first, I was using them interchangeably, but now realize the difference.

Refactoring helped make the code cleaner and more organized so it would be easier to understand without having to write the same code many times. When I first started breaking apart the tasks, I would write each condition one-by-one, but after going through class, I realized how I could combine multiple conditions using the 'or' '||' operator instead of writing them as separate statements.
